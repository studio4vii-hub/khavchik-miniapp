# Подключение «Хавчика» к Telegram

## 1. Публикация
Загрузите содержимое этой папки в корень репозитория `studio4vii-hub/khavchik-miniapp` и дождитесь публикации GitHub Pages:
https://studio4vii-hub.github.io/khavchik-miniapp/

## 2. BotFather
1. Откройте https://t.me/BotFather и создайте бота командой `/newbot` (если ещё нет).
2. Сохраните токен в защищённом месте. **Не помещайте токен в GitHub, HTML или этот чат.**
3. Выполните `/setmenubutton`, выберите своего бота, укажите кнопку `Открыть меню` и URL `https://studio4vii-hub.github.io/khavchik-miniapp/`.
4. Откройте чат с ботом в Telegram и нажмите кнопку меню.

## 3. Что работает
Сайт открывается внутри Telegram WebView, вызывает `ready()` и `expand()` и согласует цвета с приложением. Меню и тестовая корзина остаются локальными.

## 4. Что НЕ работает
- Бот не отвечает на `/start` без отдельного backend/бот-процесса.
- Тестовые заказы не отправляются в кафе.
- Авторизация пользователей и платежи не подключены.
- `initDataUnsafe` не используется как доверенный источник. Для реальной авторизации сервер должен проверять подписанные `initData` по Telegram Bot API.

Для реальных заказов потребуется сервер и секретный токен бота, хранимый только на сервере. GitHub Pages не может исполнять серверный код.
