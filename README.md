# Хавчик 2.7 — проверочная сборка

Статический демонстрационный Telegram-style интерфейс для GitHub Pages.

## Изменения
- На главной реальная фотография интерьера и блюд, предоставленная пользователем (`assets/interior-real.jpg`).
- Карточка блюда показывает фотографию целиком (`object-fit: contain`) вместо чрезмерного увеличения и обрезки.
- Небольшая корректировка вертикальных отступов и категорий.
- Фотографии блюд остаются демонстрационными и ограничены исходным качеством. Улучшение резкости не восстанавливает детали.

## Публикация
Загрузить `index.html`, `DESIGN.md`, `README.md` и папку `assets` в корень репозитория.

Платежей и отправки заказов нет.
