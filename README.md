# Хавчик 2.6 — демонстрационный прототип

Статический HTML/CSS/JS для GitHub Pages. Разместите `index.html` и папку `assets` в корне репозитория.

## Функции
Главная, меню, категории, поиск, карточка блюда, корзина, переключение самовывоза/доставки, тестовое оформление. Корзина сохраняется локально в браузере.

## Ограничения
Это не действующая система заказа еды. Цены и фотографии блюд демонстрационные, не подтверждены кафе. Доставка не рассчитывается. Оплата не принимается, персональные данные не передаются на сервер, заказ не отправляется.

## Публикация
GitHub Settings → Pages → Deploy from a branch → main / (root).
