# Хавчик — объединённое обновление

Обновлено: утверждённый баннер на главной, часы работы Пн–Вс 11:00–22:00, фирменный символ, вырезанный из фотографии настоящей вывески, и третий способ заказа «В зале» с обязательным номером столика.

**Важно:** знак на вывеске доступен только как фрагмент фотографии, поэтому его качество ограничено. Для точного брендового логотипа нужен оригинальный файл.

Тестовые заказы не передаются в кафе. GitHub Pages обслуживает только интерфейс.

Загрузите содержимое архива в корень репозитория. Папка `assets/` должна остаться папкой.
