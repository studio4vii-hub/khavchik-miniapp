# Хавчик — меню по предоставленному печатному прайсу

31 позиция, 8 товарных категорий (плов выделен в собственную вкладку).

## Публикация
Замените `index.html` в корне GitHub Pages-репозитория. Изображения встроены в HTML, дополнительных папок не требуется.

## Важно
- Цены и названия перенесены из фотографии меню, предоставленной заказчиком.
- На печатном меню не указан вес плова и объём напитков: в приложении пометка «Уточняется».
- Соусы из прайса перечислены как варианты; способ выбора варианта следует уточнить.
- Для блюд используются нейтральные заглушки, а не неподтверждённые фотографии.
- Корзина и оформление заказа пока демонстрационные: заказы НЕ передаются кафе.
- Отзывы сохраняются только на устройстве до подключения серверной базы.
- Статус «Работаем/Отдыхаем» определяется по московскому времени 11:00–22:00.
