# Хавчик 2.4 — демонстрационный интерфейс

Статический прототип для GitHub Pages. Откройте `index.html`.

- Меню, поиск, карточка блюда, корзина, самовывоз и доставка.
- Цены, фотографии и состав блюд — демонстрационные, не подтверждённое меню.
- Тестовый заказ никуда не отправляется. Не использовать для реальных заказов.
- Визуальные правила — `DESIGN.md`.

Для публикации загрузите содержимое этой папки в корень репозитория и включите GitHub Pages из `main` / `(root)`.
