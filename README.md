# Хавчик 2.5 — демонстрационный прототип

Откройте `index.html` или опубликуйте содержимое этой папки в корне GitHub Pages.

- Включены: каталог, категории, поиск, карточка блюда, изменение количества, корзина, выбор самовывоза/доставки, проверка тестовой формы.
- Данные корзины хранятся локально в браузере.
- Нет сервера, платежей и отправки заказов. Цены, блюда и фотографии в демо не подтверждены кафе.
- `interior.png` — предоставленная фотография интерьера. Остальные фотографии из предыдущего прототипа, качество некоторых требует замены.
- `DESIGN.md` содержит правила визуальной системы.

Загружайте файлы из папки в **корень** репозитория, не сам ZIP.
